# Styles Module

Path: `src/styles/app.css`

## Purpose

Application styling and theme variables.

## Responsibilities

- Define responsive workspace layout.
- Style form controls, result panels, cards, validation states, and agent activity.
- Provide theme variables for Verdant, Arcane, and Nocturne.
- Keep UI text readable across mobile and desktop widths.

When adding new result sections, prefer using existing theme variables instead of hard-coded colors.
