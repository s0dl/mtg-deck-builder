# Frontend Docs

The frontend is a React + TypeScript app that collects deck goals and presents generated deck results.

## References

## Run Locally

```bash
npm install
npm run dev
```

Set `VITE_API_BASE_URL` when the backend is not running at `http://localhost:8000`.
