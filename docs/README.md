## Where To Add New Docs

- Put system-wide design notes under `docs/`.
- Put backend API, module, and operations notes under `docs/backend/`.
- Put frontend component, styling, and client notes under `docs/frontend/`.
- Keep short module-local READMEs under `backend/app/*/README.md` only when they help engineers working directly in that module.
